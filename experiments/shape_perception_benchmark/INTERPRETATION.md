# P0-4.6 结果简要解读与验证方法（排除水体 / 地理后）

本轮**完全排除 Overture Maps、水体候选与经纬度**，只在纯二维闭合轮廓上回答一个问题：
*一个经人类感知实验验证的形状模型，能否找到人眼判断相似的轮廓，并胜过 EarthGlyph 现有几何匹配器？*
不改正式检索默认、不扩大地貌库、不覆盖 P0-4 / P0-4.5。数字均取自
[`results/metrics.json`](results/metrics.json) 与 [`results/human_metrics.json`](results/human_metrics.json)，
逐条证据见 [`notes.md`](notes.md)。

## 一、结果解读

**1. 官方神经近似现已本地实跑（numpy 端口）；原始 109 维描述子引擎仍不可得。**
用户于 2026-11-08 手动下载官方工具箱到 `shapeComp_17_12_2024/`（gitignored，上游仅"please cite"、无再分发许可）。
`earthglyph/shape_benchmark/shapecomp_port.py` **只翻译官方 MATLAB 预处理**（质心 / 弧长重采样 / min-max 定位 /
顺时针强制 / 栅格化），并用 numpy 前向**逐字运行作者自己的 Keras `.h5` 权重**（h5py，**无 TensorFlow、无重训练、无 GPU**）。
这是官方神经近似在 Python 中执行，**不是**自写描述子冒充复现。KerNet1=`shape2sc22a.h5`（768 维轮廓 MLP），
KerNet2=`im2sc22d.h5`（40×40 二值图 CNN）。**忠实度对发布*网络*输出验证**：KerNet2 对 H2 发布坐标**近乎精确**
（逐维 r 0.9982、成对 Spearman 0.9989、RMSE 0.0065）；KerNet1/2 对 Figure 8 发布列 Spearman 0.980/0.957
（残差是输入溯源——存档轮廓是原始非均匀显示轮廓，非网络精确输入；跳过重采样会塌到 ~0.56，证明流水线必需且正确）。
`S0` 仍是作者**发布的官方 22 维 ShapeComp MDS 坐标**（原始 109 描述子经 MDS 投影；H1 500 + H2 15），`dist == ‖SC1−SC2‖` 残差 4.4e-16，
**不能给新形状打分**故仅 D1；`S0K1/S0K2` 是**实跑官方权重**、可打分新形状、进入一切检索阶段。
历史阻断证据（CP1：Dropbox/Drive/Sites 全阻断、无 MATLAB/Octave）仍存档；2024 工具箱**不含** 109 维引擎，
故原始 ShapeComp 对新形状的精确投影仍不可得，只有两个神经近似可跑。从原始 `.mat` 复算（非抄论文）：H1 Pearson **−0.904** / Spearman **−0.911**，H2 Pearson **0.778**。

**1b. CP7-A 逐函数审计把"移植对不对"与"输入是不是那份输入"分开了（2026-11-09）。**
对 15 个 H2 形状搜索"循环起点 × 遍历方向 × 存档两文件"后，**8/15 与作者发布的 KerNet2 坐标差 < 1e-6（中位 1.5e-07）**——
机器精度一次性钉死权重读取、层序、conv/pool/ReLU 序、C-order flatten、`inpolygon`、`flipud` 与两级重采样。
**其余 7 例仍在 4.8e-3–1.8e-2，记为"未归因"**：不能说全部残差都来自预处理（D57）。
KerNet1 只确认 768 维**输入次序**（消融 0.184 ≪ 1.922 / 2.622），网络级忠实度**未**钉到机器精度。
新增硬事实：栅格化**单像素翻转 = 18.5% 嵌入范数**（D59，为 CP7-C 的旋转包装设定上界）；
填充规则已从 GEOS 换成 MATLAB 原语 `inpolygon` 直译并在含自交环的 75 条官方轮廓上**逐像素 0 差异**（D58）；
非法输入改为显式 `ShapeCompInputError` 拒绝，不再可能悄悄产出 NaN/零向量。权重 SHA256 与来源页入库、二进制仍 gitignored（D60）。

**1c. CP7-B 修正了 D5(a) 的统计单位：1750 行 → 250 个"被评分的形状对"（2026-11-09）。**
D5(a) 把 250 对 × 7 角度堆成 1750 行后按**行**独立重抽样，等于把同一形状的 7 次重复观测当作 7 个独立受试材料
⇒ **CI 系统性偏窄约 2 倍**（实测宽度 ×1.49–2.13），**点估计不动**（本来就只是描述结果）。
修正后的区间被**未参与本轮的 D1** 独立复核：D1 以 250 对为单位、未旋转，故对"旋转不改变距离"的臂二者必须重合
——E0 宽度 **0.1468 = D1 0.1468**、E1 **0.1159 = 0.1159**、E3 0.1054 ≈ 0.1066（差 0.0012，E3 的旋转搜索随角度变）。
配对（所有臂共用同一 replicate）后 21 个臂序 **19 成立**，**E1 vs S0K2+rot**（+0.0085 [−0.0287,+0.0467]）与
**S0K1 vs S0K2 naive**（−0.0239 [−0.0496,+0.0015]）判为**不可区分**；另有 5 个差由配对检验补上（E3>S0K1+rot 等）。
角度按**固定设计因子**作推断（头部）；把角度也随机抽样只有 2 条次序失效，且 naive 臂区间剧烈变宽（0.113→0.453）。
既有 D5 产物**一字未改**：`--stage d5b` 只读存量 CSV 并以"必须复现旧值"为准入闸门（最大偏差 0.000e+00），
新数值另存 `d5_grouped_*` 并记录旧文件的 SHA256。最后一点须始终写明：**旋转后沿用原有人类评分是假设**
（未复测任何旋转对），故 (a) 度量"对图像变换的不变性"，不是"人类对旋转形状的判断"——主判据仍是 (b) 检索（D54/D63）。

agreement ρ 把相关统一改述为"距离 vs 人类不相似度"，**越大越好**：

即端口忠实复现了官方网络的人类预测力，且二者均显著胜过所有 EarthGlyph 臂。
EarthGlyph 臂中 **E3 最佳**，接近人类留一噪声上限 **0.779**；网络臂超过单个被试的一致性。

**3. 真实闭合轮廓检索（D2–D4，MPEG-7 1398 形状 / 70 类；S0 缺席，S0K1/S0K2 为实跑官方网络）。**

  **E0/E1/E3 行与 CP4 逐位一致**（确定性核验通过）。
- **D3** 五族结构变体全部排在粗干扰之上；E1 压干扰最深（rank 556–1387），网络居中（S0K1 41–1103、S0K2 42–1077），
  E0 放干扰到 rank 23。角色是**构造假设，非人类真值**。
- **D4**（关键整合阻塞）：**官方网络不旋转不变**——查询旋转 37°/90°/191° 后 Top-10 overlap 塌到 **0.00**、
  自匹配跌至 rank 301（fork-1 90° S0K1）；镜像形状依赖（bat overlap 0.05、heart 0.82）。
  E0/E1 旋转不变（overlap 1.00）；**E0 不镜像不变**（0.00，rank 246/163）；**E3 的 15° 网格**使 37°/191° 减半至 0.54。

  需旋转搜索/不变包装（本轮未验证）。成本：网络**一次性**打分图库（~20 s）后每查询≈**0 s**（远低于 E3 55 s/查询），但旋转敏感。
- **D5（Checkpoint 6 · 已验证的旋转搜索）**：给 S0K 臂加**与 E3 同网格（24 步 / 15°）的查询侧旋转搜索**后，
  在**同一旋转条件**下（旋转是唯一变量、共享人类真值）：
  **检索**——旋转下 Top-10 overlap 由 naive 0.15 升至 **0.91–0.94（≈E3）**，精确目标在 **21 例**旋转查询
  （3 目标 × 7 个非零角度，**口径已排除 0° 对照**）中 **S0K1+rot 20/21、S0K2+rot 19/21 回 rank 1**
  （仅网格外 37°/191° 少数落 rank 2–6，即 E3 已披露的半步网格局限）；naive 仅 1/21 与 4/21，且跌至 rank 244–297；
  **E0/E1/E3 在每个旋转查询上都是 rank 1**。

  （同样为 `250 对 × 7 个非零角度 = 1750 行`，不含 0°）；
  但**仍不胜 E3 +0.839 / E1 +0.782**，且**牺牲峰值**（φ=0 时 S0K1 0.903→0.763，多姿态取最小令不同形状撞近——该列仅校验，非工作点）。

  但人类相似度预测力未因此超过 EarthGlyph 现有 E3——整合与否由用户定，不改正式默认。**
- **判据对齐（本项目主判据是"随机旋转下查找效果最好"，即 (b)）**：(a) 与 (b) 回答两个不同问题，
  **不能互相替代**——(a) 问"距离排序像不像人的相似度判断"，(b) 问"查询被随机转过之后还能不能捞回对的那个形状"。
  按主判据 (b) 排序：**E0 = E1（overlap 1.000、21/21 rank 1）> E3（21/21 rank 1，overlap 0.916/0.674）
  ≈ S0K1+rot（20/21）≈ S0K2+rot（19/21）≫ naive（1/21、4/21）**。
  **故网络在 (a) 上的历史优势（CP5 的 +0.072）并不构成对 (b) 的承诺**：它从来不是旋转查找的赢家，
  本轮的价值是把它从"旋转不可用"做到"E3 同档可用"，而不是反超 E0/E1。

## 二、验证方法（为什么这些数字可信）

1. **方向统一**：H1 评分是相似度 → 好模型的距离相关为负；统一改述为 agreement（正=更好）。
   H2 目标是数字化排列里的距离 → 正相关。两者语义不同，**永不合并**。
2. **判据与问题对齐**：本项目主判据是**随机旋转下的查找效果**（D5 (b)），(a) 的 agreement 只是"该表示是否
   捕捉人类相似度"的证据（源自 P0-4.6 原始研究问题），**两者不得互相替代**；按 (b) 报出的赢家是 E0/E1。
3. **被试级保留 + 两级 bootstrap**：保留 250×14 逐被试矩阵，不当独立样本；对"对 + 被试"两级重采样
   2000 次（seed 20261107）得 CI。边际 CI 重叠 → 改用**配对** bootstrap 检验臂间差值。
4. **噪声上限**：被试间两两相关中位 **0.601**、留一中位 **0.779**，作为"人类自己有多一致"的参照系。
5. **不挑选**：全 250 对都算；`failure_cases.csv` 保留每一对，图只展示分歧最大的 6 个（排序规则公开）。
6. **公平检索**：所有臂同一候选集；扩集时**继承** E1 归一化器（否则"加干扰"与"重缩放"成同一变量），
   反事实实测重拟合会动 27/91 尺度、最大偏移 22.1%；**完整排名**存 `d2_full_rankings.npz`，不只 Top-10。
7. **展示对齐不改排名**：`align_for_display` 臂无关、仅用于画图，绝不参与排名。
8. **诚信边界**：类别 / 结构 / 命名 / 模型对模型 / 数字化辅助均不当人类真值；S0 明确标"发布坐标、非本地运行"；
   CP1 误称 Figure 8 刺激不在存档内已撤回（实带 1000 轮廓，无人类评分、与 H1 不相交，仅模型对模型）。
9. **工程验证**：`pytest` **792 passed**（含 15 个端口测试，0 跳过）、`ruff` 全过、`mypy` 39 文件无问题；
   来源 sha256 + HTTP Range 传输统计（12.3 MB / 存档 308 MB）+ 复现命令入库。
   **确定性核验**：加入 S0K1/S0K2 重跑后 E0/E1/E3 的 D2/D4 行与 CP4 逐位一致；加入 D5 后 D1–D4 文件未重跑，
   其 naive 路径算术未变（`rotation_search` 默认 False），φ=0 naive 臂复现 CP5 D1 值到小数第三位。
10. **口径可审计**：每个头部统计都写明分母（如 1750 = 250×7、21 = 3×7），且 0° 对照一律单独存放、不进头部数字。

## 三、边界与下一步

**官方神经近似已本地实跑并验证**（KerNet2 对发布坐标近乎精确），且 **E3→S0 的 +0.072 头部空间已被实跑网络兑现**：
S0K1/S0K2 与发布 S0 统计不可区分，并显著胜过 E3（E3−S0K1 −0.064，排除 0）——**注意这是在"姿态已对齐"条件下成立的 (a) 结论**。
但**现成接入仍受限**：D4 实测官方网络**不旋转不变**（旋转后 overlap 0.00、自匹配 rank 至 301）；原始 109 维描述子引擎仍不可得（精确投影）；权重无再分发许可（gitignored，运行时读本地副本）。
**已做（Checkpoint 6）**：
(a) ✅ 给实跑网络加**旋转不变包装**（E3 式 24 步 / 15° 查询侧旋转网格搜索）并重测——D5 证：**检索稳定性达 E3 同级、目标基本回 rank 1**，
旋转下人类 agreement 由 ~0.44 救回 ~0.75–0.77，**但未超 E3（0.839）**，且牺牲 φ=0 峰值（0.903→0.763；

"旋转可查找的 ShapeComp"是否纳入产品由用户决定。
