本轮**完全排除 Overture Maps、水体候选与经纬度**，只在纯二维闭合轮廓上回答一个问题：
*一个经人类感知实验验证的形状模型，能否找到人眼判断相似的轮廓，并胜过 EarthGlyph 现有几何匹配器？*
不改正式检索默认、不扩大地貌库、不覆盖 P0-4 / P0-4.5。数字均取自

## 一、结果解读

**1. 官方 ShapeComp 本地没跑成，但其发布坐标可作一臂。**
三个分发 host（Dropbox / Drive / Sites）全网络阻断，本机无 MATLAB / Octave / TensorFlow，
未装商业软件、未买许可、未写 109 维移植。`S0` 只能是作者**发布的 22 维坐标**（H1 500 + H2 15），
`dist == ‖SC1−SC2‖` 残差 4.4e-16；它**不能给新形状打分**，故缺席一切检索阶段。
从原始 `.mat` 复算（非抄论文）两个头条数：H1 Pearson **−0.904** / Spearman **−0.911**，H2 Pearson **0.778**。

**2. 与真实人类评分的相关性（D1，主真值 H1：250 对 × 14 被试，未挑选任何对）。**
agreement ρ 把相关统一改述为"距离 vs 人类不相似度"，**越大越好**：

| 臂 | agreement ρ | 95% CI | 备注 |
|---|---|---|---|
| **S0** 官方发布坐标 | **0.911** | [0.856, 0.918] | 仅这 500 刺激，非本地运行 |
| **E3** Shape Context + 旋转搜索 | **0.839** | [0.762, 0.868] | 可跑臂最佳，58 s/查询 |
| **E1** EarthGlyph 自写 91 维 | **0.782** | [0.703, 0.819] | 最耐变换，12 s/查询 |
| **E0** 几何对齐 | **0.683** | [0.589, 0.736] | 最快 0.1 s，但不镜像不变 |

可跑臂中 **E3 最佳**，接近人类留一噪声上限 **0.779**；S0 超过单个被试的一致性。
排序经**配对**两级 bootstrap 检验，六个差值全部排除 0（最弱 E3−E1 = +0.057 [+0.006, +0.107]）。

**3. 真实闭合轮廓检索（D2–D4，MPEG-7 1398 形状 / 70 类）。**
- **D2** T2/T3 平均 class-recall@10 = E0 **0.717** / E1 **0.833** / E3 **0.917**（类别≠人类相似度，但与 D1 排序一致）；
  E0 对 `tree-1` 返回 flatfish/jar。**T3 无区分度**：异类硬干扰 0/6 进入任何臂 Top-10 → 诚实负结果，干扰物太"粗"。
- **D3** 五族结构变体全部排在粗干扰之上（角色是**构造假设，非人类真值**）。
- **D4** 实测缺陷：**E0 不镜像不变**（Top-10 overlap 0.00，自匹配 rank 246/163）；
  **E3 的 15° 旋转网格**使 37°/191° overlap 减半至 0.538；E1 最耐变换但镜像仍丢 2/3。

## 二、验证方法（为什么这些数字可信）

1. **方向统一**：H1 评分是相似度 → 好模型的距离相关为负；统一改述为 agreement（正=更好）。
   H2 目标是数字化排列里的距离 → 正相关。两者语义不同，**永不合并**。
2. **被试级保留 + 两级 bootstrap**：保留 250×14 逐被试矩阵，不当独立样本；对"对 + 被试"两级重采样
   2000 次（seed 20261107）得 CI。边际 CI 重叠 → 改用**配对** bootstrap 检验臂间差值。
3. **噪声上限**：被试间两两相关中位 **0.601**、留一中位 **0.779**，作为"人类自己有多一致"的参照系。
4. **不挑选**：全 250 对都算；`failure_cases.csv` 保留每一对，图只展示分歧最大的 6 个（排序规则公开）。
5. **公平检索**：所有臂同一候选集；扩集时**继承** E1 归一化器（否则"加干扰"与"重缩放"成同一变量），
   反事实实测重拟合会动 27/91 尺度、最大偏移 22.1%；**完整排名**存 `d2_full_rankings.npz`，不只 Top-10。
6. **展示对齐不改排名**：`align_for_display` 臂无关、仅用于画图，绝不参与排名。
7. **诚信边界**：类别 / 结构 / 命名 / 模型对模型 / 数字化辅助均不当人类真值；S0 明确标"发布坐标、非本地运行"；
   CP1 误称 Figure 8 刺激不在存档内已撤回（实带 1000 轮廓，无人类评分、与 H1 不相交，仅模型对模型）。
8. **工程验证**：`pytest` **777 passed**、`ruff` 全过、`mypy` 38 文件无问题；
   来源 sha256 + HTTP Range 传输统计（12.3 MB / 存档 308 MB）+ 复现命令入库。

## 三、边界与下一步

但发布空间在人类评分上显著领先，**E3→S0 的 +0.072** 是近似 / 混合方案的头部空间。建议两项**有界**研究：
(a) Figure 8 检索臂（998 可加载形状 × 四条发布坐标路线，模型对模型、披露预处理混淆）；
