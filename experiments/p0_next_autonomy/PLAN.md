# P0 收官长期自主工程 — 工作计划

> 本目录是本轮自主工作的唯一进度记录；每完成一个子任务打一个 Git 检查点并推送。

## 范围与边界（照抄简报，不可放宽）

- 自主权限：审计代码、找边界情况、写测试、小范围兼容性修复、CPU 实验、
  P0-6 评分/汇总工具、静态部署契约验证、GitHub CI、日志与 Git 检查点、
  自主选择下一个任务。
- 未经授权禁止：大规模数据下载、付费云资源、对外公开部署、修改外部账号配置、
  不可逆破坏性操作。
- 默认禁止修改（生产修正需先独立证明根因/影响面/前后 diff，再做最小改动）：
  正式 Fourier 粗筛与精排数学；`fourier_align` 等生产默认参数；已冻结的 P0-5
  实验数据与结论；P0-6 真人采集协议与成功判据；真实水体索引既有构建产物；
  ShapeComp 历史实验结果及其统计口径。
- 不得通过降低测试要求、修改评价分母、删除困难样本或改变冻结阈值来制造性能提升。

## 执行顺序（简报推荐，允许有理由调整）

`A 基线审计 → C 评分体系 → D 静态验证 → B M1 定向实验 → E CI → F 决策`

理由：C 是 P0 门禁唯一入口（P0-6）的最后一公里，价值最高；D/B/E/F 均不依赖
真人数据，可并行推进。实际执行顺序与偏离理由记录在 PROGRESS.md。

## 各阶段验收标准

- **A 基线审计**：远端/本地 SHA 一致性复核；四项 Python 门禁 + Web 四项门禁
  实测通过；真实索引在位（839 候选）；P0-6 真人数据 = 0 份；M1 能力清单；
  主要风险清单。产出：RESULTS.md §1。
- **C P0-6 评分体系**：`scripts/score_p06_judgements.py` 按冻结协议 §5–§6
  读取自评+盲评 CSV，验证结构/枚举/映射/重复/缺失/非法值，计算主判据
  （抽屉自评 Top-10 含 similar 的有效最终查询占比，Go = 严格 >50%）+ 双口径
  报告 + 拒绝率 + 每参与者分布 + 可复现 Go/No-Go 判定与证据；配套 SYNTHETIC
  TEST 端到端测试覆盖简报列举的全部边界；真实采集操作说明。协议歧义全部
  列口径与影响，绝不静默选有利分母。
- **D 静态验证**：真实索引最小静态导出（Float32 特征/轮廓点/ID/经纬度/数据
  版本与 sha256/schema 版本）；Python/TS 金丝雀向量契约扩展到全链路
  （重采样/平滑/质心 RMS/Fourier/列序/粗排距离/循环对齐）并量化容差；
  Vite 构建 + 本地静态服务冒烟；Qoder Sites 路径可行性文档化（不部署）。
- **B M1 定向实验**：采样密度敏感性（同几何不同密度的 scale/tolerance/
  junction 合法集/status/Top-K 配对实验）；端点切向退化（短线/往返/重复点/
  近 180° 尖端/极端非均匀采样/零向量 NaN）；全局拼接歧义边界。每个假设
  VERIFIED / NOT VERIFIED / BLOCKED + 回归测试。
- **E CI**：GitHub Actions Python（pytest/ruff/mypy）+ Web（npm ci/vitest/
  typecheck/build）；干净环境可复现（无本地真实索引也能跑）；真实数据测试
  显式分类不静默跳过；依赖审计。未实际远端运行过则只写"已提交/待运行"。
- **F 决策**：基于本轮全部证据选一个方向（F1 地理扩容规划 / F2 精排改进
  配对实验 / F3 M2 复杂区域接口研究 / F4 出界不选），允许证据否决。

## 长期循环（每个子任务）

检查现状 → 提出假设 → 设计验收 → 最小改动 → 测试 → 独立核验 → 记录
（PROGRESS.md / RESULTS.md）→ Git 检查点（提交+推送+`git ls-remote` 核验）
→ 选下一个任务。遇阻塞记录后切换到未阻塞工作，不停止。
