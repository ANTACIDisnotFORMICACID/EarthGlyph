# PROJECT_SPEC — 需求、MVP 范围与验收

> 完整产品设计与交互细节见 [`DESIGN_V1.md`](DESIGN_V1.md)。本文件只固化范围与验收判据，避免重复。

## 1. 产品定位

用户绘制闭合轮廓 → EarthGlyph 从开放地理数据检索形状相似的真实湖泊 / 水库 / 池塘 → 展示真实地理位置、轮廓叠加、可分享结果。

## 2. V1 / MVP 范围

**包含：**
1. 手绘闭合图形输入（自动闭合、清空、撤销、镜像 / 旋转开关）。
2. 地理轮廓相似性检索（两级：特征粗筛 → 几何精排 → 去重）。
3. 真实地理位置展示（MapLibre + 真实矢量边界）。
4. 轮廓叠加比较（草图 vs 真实地物，可调旋转 / 透明度）。
5. 地图交互与探索。
6. 结果分享（URL 编码查询草图 + 候选 ID；导出 SVG/PNG 发现卡片）。

**不包含（本次比赛明确不做）：**
任意线条 / 汉字 / 跨模态检索、全球卫星影像抓取、AI 聊天、账号体系、点赞榜、自动扩展到道路 / 岛屿、训练遥感模型、运行时大模型调用。

## 3. 不可妥协的要求

- 每个结果必须有真实几何、坐标、来源 ID、数据版本；禁止随机 / 预设生成结果。
- 明确标注"当前搜索覆盖的数据集 / 地区 / 地物类型"；不宣称全球全部卫星图像。
- 结果较差时如实展示"未找到特别接近的形状"，允许重画。
- 不虚构水体名称；无名称则用地物类型 + 大致区域 / 坐标。
- 每条结果可在地图上打开，不只是缩略图。
- 地图底图与原始数据展示正确署名与许可。

## 4. MVP 验收条件

| 维度 | 验收标准 |
|------|----------|
| 数据真实性 | 全部结果可回查真实来源 ID、经纬度、数据版本；过滤 Point/LineString/海洋切片。 |
| 算法可复现 | 固定草图 + 固定种子可复现同一 Top-K 排序。 |
| 检索效果 | Go/No-Go：≥10 个真实用户手绘轮廓中，多数能在 Top-10 找到肉眼明显相似的真实地物（判据见 `EXPERIMENTS.md`）。 |
| 前端流程 | 打开页面到首个真实结果 ≤ 3 步；搜索不冻结页面（Web Worker）；移动端可手绘与查看结果。 |
| 分享 | 分享链接能复原同一查询或锁定具体结果；发现卡片仅用自有草图与开放矢量轮廓。 |
| 部署 | 公网 Qoder Sites 链接无登录门槛，评委可直接体验；许可署名正确。 |

## 5. 阶段门禁

**P0 未通过前不进行大规模 Web 产品开发。** 若纯几何检索无法形成吸引力，按 `DESIGN_V1.md` §6.4 调整产品定位，而非夸大能力。
