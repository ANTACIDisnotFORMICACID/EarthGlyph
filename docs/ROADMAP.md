# ROADMAP — 开发阶段、里程碑与阶段验收

> 比赛倒排时间线见 [`DESIGN_V1.md`](DESIGN_V1.md) §7。本文件固化阶段交付物与验收门禁。

**总截止：** 2026-11-30 前可公开访问的 MVP。

## P0：真实数据与检索可行性验证（最高优先级）

**交付物：**
1. 成功拉取官方真实 water GeoParquet（小 bbox 起）。
2. 完成 Polygon/MultiPolygon 过滤、投影、清洗、重采样。
3. 输出真实湖泊轮廓缩略图 + 坐标 + 来源 ID。
4. 至少一种检索 Baseline（Hu 矩 / Fourier），生成真实 Top-10 结果图。
5. 旋转 / 缩放 / 扰动鲁棒性测试 + 真实手绘测试。
6. 失败案例分析与 Go/No-Go 结论。
7. 同步验证 Qoder Sites 静态发布路径可行。

**验收门禁：** 通过 `EXPERIMENTS.md` §6 的 Go 判据。**未通过不进入 P1 大规模开发。**

> **P0 期间的并行子阶段（不改变门禁，2026-11-09）** — P0-4.6 地理无关的形状感知检索基准
> `experiments/shape_perception_benchmark/`（CP1–CP7 全部完成）：用真实人类相似度评分与官方
> ShapeComp 网络对照 E0/E1/E3 三条几何基线。结论是**不把 ShapeComp 整合进生产检索器**——
> 两个目标由不同臂胜出，没有任何一支同时占优（判据 D54，实测 D65/D67/D71）。
> 门禁状态**不因此改变**：仍以 `EXPERIMENTS.md` §6 为准（**未通过**，待 P0-5 合成扰动分级曲线与
> P0-6 ≥10 个不同真人手绘 + 人工肉眼判读）。本轮明确未做 Web UI、未引入真实水体数据。

## P1：基础 Web 产品

**交付物：** React+TS 绘图画布（闭合曲线 + 输入检查）、Web Worker 载入索引与检索、候选卡片 + 地图定位 + 轮廓覆盖、≥3 个经真实搜索验证的示例。
**验收：** 打开页面到首个真实结果 ≤3 步；搜索不冻结；示例均为真实检索结果。

## P2：检索与交互优化

**交付物：** 精排算法、去重、候选多样性；真实手绘测试并解决前几项失败类型；手机交互、地图懒加载、索引压缩、错误处理；覆盖范围 / 来源 / 许可说明。
**验收：** 真实手绘 Top-10 质量较 P0 提升且有实验记录；移动端可用。

## P3：分享与完整产品体验

**交付物：** 结果叠加比较、分享链接与发现卡片；Playwright E2E 覆盖完整流程；弱网 / 低性能设备 / 空结果测试；录制"画图→真实发现"无剪辑核心演示。
**验收：** E2E 通过；分享链接能复原查询或锁定结果。

## P4：部署与比赛提交

**交付物：** Qoder Sites 部署（手机 + 无痕窗口复测）；发布源码 / 算法文档 / 数据来源说明；按 LifeHack 格式发布介绍；确认真实数据、授权、演示可重现；提前提交。
**验收：** 公网链接无登录门槛，评委可直接体验；许可署名正确；不夸大成"全球卫星影像任意搜索"。

## 阶段依赖

```
初始化(完成) → P0 → [Go] → P1 → P2 → P3 → P4 → 比赛提交
                     └[No-Go]→ 改数据/算法 或 调整产品定位
```
